# Aigarth Garden Labs: Observatory for Hyperidentity Evolution

## Project Overview

### Mission
Create a public, decentralized observatory to empirically explore whether Qubic's Hyperidentity mechanism can demonstrate recursive self-improvement and emergent agentic behavior.

### Core Hypothesis
Useful Proof-of-Work (uPoW) transforms computational mining into genuine evolutionary pressure on a global "Intelligent Tissue". Hyperidentity enables networks to improve themselves or other networks, potentially contributing to open-ended intelligence beyond static model architectures.

## Current State (May 2026)

### Achievements
- Real Qubic mining with active seed contributions
- Stable ternary hyperidentity evolution simulator
- Consistent performance plateau (0.3035–0.3039) across 120+ generations
- Full automation infrastructure
- Public, beginner-friendly GitHub repository
