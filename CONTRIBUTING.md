# Contributing to Aigarth Garden Labs 🌱

## Welcome, Gardeners!

We are building a public, decentralized observatory to study emergent intelligence through Hyperidentity and Useful Proof-of-Work (uPoW).

### Our Mission
- Empirically explore recursive self-improvement
- Maintain radical transparency
- Document computational evolution

## Ways to Contribute

### 1. Run Simulations
```bash
# Basic simulation run
cd simulations
python run_experiment.py \
  --mut 0.20 \
  --gens 120 \
  --pop 128 \
  --seed 2354D8B800D56AD4831F93FA895050EA74C4778CDC1055133AFA5CC4C7B8C984
```

### 2. Analyze Results
- Review fitness curves in `results/`
- Compare multi-run comparisons
- Look for:
  * Stability patterns
  * Mutation resilience
  * Emergent behaviors

### 3. Improve Infrastructure
- Enhance simulation frameworks
- Optimize log parsing
- Develop new analysis tools

### 4. Documentation
- Update README
- Add research notes
- Share observations

## Ethical Guidelines
- Prioritize empirical data
- Avoid speculative narratives
- Maintain open-source methodology

## Technical Requirements
- Python 3.9+
- NumPy
- Pandas
- Matplotlib
- (Optional) Qubic mining setup

## Contribution Process
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests
5. Submit a pull request

## Code of Conduct
- Respectful communication
- Scientific rigor
- Collaborative spirit

**The Garden grows with every contribution.** 🌱
